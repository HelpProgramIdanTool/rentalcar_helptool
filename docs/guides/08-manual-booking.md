# Ручной заказ без оферты

1. Нажмите **Новый заказ** в меню или **Новый заказ вручную** в таблице заказов.
2. Для существующего клиента выберите карточку в верхнем списке и нажмите **Заполнить**.
   Для нового клиента заполните поля, оставив выбор существующей карточки пустым.
   Необходим хотя бы один контакт: email или телефон. Общий email не объединяет разных клиентов.
3. Выберите фирму и группу автомобиля. Введите даты, места, контакты, имена водителей
   латиницей (каждого с новой строки), добавки, рейс и отель при необходимости.
4. Укажите **Чей заказ**:
   - **Мой заказ** — ответственный определяется по вашей учётной записи сотрудника;
   - **Заказ сотрудника** — выберите ответственного сотрудника;
   - **Заказ субагента** — выберите субагента; ответственного сотрудника можно указать отдельно.
5. Нажмите **Пересчитать**. Используются действующие тарифы. Если депозит отсутствует,
   появится окно ввода с разовым или постоянным сохранением.
6. Проверьте сумму и подтвердите создание черновика заказа.
7. В карточке нажмите **Подготовить письмо поставщику**, проверьте и сохраните текст.
   Выберите **Скопировать** для ручной отправки, **Выслать из системы** для отправки
   приложением либо **Сохранить черновик** для продолжения позже.

Заказ появится в общей таблице. Оферта при этом не создаётся. Номер полученной резервации
всегда вносится позже: нажмите **＋ Внести номер** в таблице заказов.

Кто внёс запись и кто отвечает за клиента — отдельные сведения. Телефон субагента
попадает в письмо как дополнительный контакт с пометкой `Sub-agent`.
Сотрудников и субагентов добавляют в соответствующих справочниках; ссылки есть в форме
для пользователя с доступом к настройкам. Комиссии на этом этапе не рассчитываются.

Изменённые контакты существующего клиента сохраняются в заказе, не переписывая его карточку.
Повторное подтверждение той же формы открывает уже созданный заказ.
