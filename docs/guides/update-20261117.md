# Обновление 2026.11.17.1

Новый формат только для NEW One Rent; UPDATE и другие поставщики сохраняют прежний формат.
Все водители в Customer через ` / `; после Deposit — Price calculation, формула и итог.

1. Закончить работу с заказами. В Render Shell выполнить
   `uv run python scripts/render_backup.py` и дождаться `BACKUP SUCCESS`.
2. В Render выбрать Manual Deploy → Deploy latest commit. Pre-deploy выполняет
   `uv run python manage.py migrate --noinput`: ожидаются миграции suppliers 0058 и 0059.
3. Дождаться Live. Проверить версию 2026.11.17.1 в программе.
4. Открыть предпросмотр письма нового тестового заказа One Rent без отправки.
   Проверить всех водителей, английские даты, места, рейс, выбранные услуги,
   Deposit и Price calculation. Сохранённый старый черновик автоматически не меняется:
   для замены есть действие «Собрать по формату поставщика» с подтверждением.
5. Проверить, что UPDATE и другой поставщик сохранили прежний формат.
6. После проверки выполнить новую резервную копию.

Шаблон и названия услуг находятся в карточке поставщика. Миграция включает формат
только для существующего One Rent с пустым новым шаблоном. Настроенный шаблон
повторно не заменяется. Суммы заказов, история писем и реальные отправки не меняются.
Локальную SQLite на сервер не загружать. Рабочая PostgreSQL остаётся на сервере.

Этот выпуск не применяет отдельную команду настройки тарифа молодых водителей.
Её выполнение после предыдущего выпуска ещё требует подтверждения владельца;
см. `young-driver-rate-update.md`.
