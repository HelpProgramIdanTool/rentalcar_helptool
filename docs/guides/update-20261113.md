# Общее обновление 2026.11.13.1

Это обновление кода, не повторный перенос базы. Серверная PostgreSQL остаётся
источником рабочих заказов. Локальную SQLite на сервер не загружать.

## Установка

1. В Render Shell выполнить `uv run python scripts/render_backup.py`.
   Продолжать только после сообщения `BACKUP SUCCESS`.
2. Закончить открытые формы и временно не отправлять письма при развёртывании.
3. Manual Deploy → Deploy latest commit. Миграции добавляют только таблицу
   справочника и включают существующие цепи Kaizen, не меняя тарифы.
4. Дождаться Live, проверить версию 2026.11.13.1.
5. Войти владельцем на `/admin/vehicle-category-map/`. Загрузить закрытый файл
   `private_uploads/vehicle-category-mapping/20261113/approved-mappings.json`.
   Без галочки сначала проверить: 14 категорий, 144 соответствия. Затем выбрать
   тот же файл с галочкой применения. Пустые/«Нет» из Excel не импортируются.
   Явно выбранные активные группы становятся видимыми в офертах; прежняя видимость
   и прежние соответствия сохраняются в закрытой папке перед изменением.
6. Проверить карточку уже существующего заказа, отсутствие второго поля имени,
   месячные итоги, кнопку ручной передачи UPDATE, направление текста оферты.
   Проверка письма — только на собственный адрес, не клиентам.
7. Выполнить новую резервную копию после применения справочника.

## Ограничения

- Ранее отменённые клоны без записанного происхождения автоматически не связываются.
  Для них нужны точные номера исходного заказа/оферты и копий.
- Уже полученные письма не меняются. Проверить новое письмо в Gmail на компьютере
  и Android. HTML-проверки не заменяют проверку конкретного почтового приложения.
- Старые ярлыки могут сохранять прежнюю иконку в кеше. При необходимости добавить
  ярлык заново. Поддержка установки зависит от браузера; офлайн-работа не добавлялась.
- При проблеме с кодом возможен возврат предыдущего коммита без удаления новой
  таблицы. Не восстанавливать старую базу поверх новых заказов. Резервная копия
  справочника предназначена для отдельного возврата конфигурации.
