# Подключение Gmail

Проект никогда не хранит пароль Gmail в Git.

## 1. Включить двухэтапную аутентификацию Google

В аккаунте Google откройте раздел **Безопасность** и включите двухэтапную
аутентификацию. Это дополнительная защита входа в аккаунт.

## 2. Создать пароль приложения

Откройте страницу **Пароли приложений** в аккаунте Google. Создайте отдельный
пароль для проекта Rent a Car. Google покажет пароль из 16 символов.

Пароль приложения — это отдельный пароль только для программы. Это не обычный
пароль от Gmail.

## 3. Сохранить данные только на своём компьютере

В PowerShell выполните команды, заменив примеры своими данными:

```powershell
[Environment]::SetEnvironmentVariable("GMAIL_ADDRESS", "your-address@gmail.com", "User")
[Environment]::SetEnvironmentVariable("GMAIL_APP_PASSWORD", "your-16-character-app-password", "User")
```

Закройте и снова откройте VS Code. После этого запустите проект заново.

Не отправляйте пароль в чат и не записывайте его в файлы проекта.

## 4. Проверить

Создайте тестовую оферту на свой email и нажмите **Выслать оферту клиенту**.
Проверьте папки «Входящие» и «Спам».

Если обе переменные не заданы, проект остаётся в безопасном режиме: письмо
печатается в терминале, но не отправляется в интернет.
