# Заказы, требующие внимания

В боковом меню откройте «Требуют внимания». Красное число — количество
заказов в очереди, а не количество отдельных ошибок.

В список попадают видимые, не скрытые заказы:

- «Ожидает подтверждения» без номера поставщика;
- «Ожидает изменения» после отправки обновления.

Черновики, отменённые и скрытые заказы не выводятся. Ближайшие даты получения
машины сверху. Для ожидания показывается последняя успешная отправка; если
записи отправки нет, показывается время последнего изменения заказа.

Введите номер поставщика и сохраните. Заказ станет подтверждённым без
пересчёта цены. Система проверяет повторение номера у этого же поставщика.

Для подтверждения изменений загрузите новый ваучер и отметьте, что проверили
его содержание. Подходит также ваучер, уже загруженный после последней
отправки изменения. Старый документ не закрывает ожидание. Само добавление
файла в карточке не подтверждает изменения.

В этой очереди владелец/администратор видит все заказы, сотрудник — созданные
им или назначенные ему. Это ограничение относится к новой очереди и её
действиям. Полное ограничение остальных страниц программы отдельной ролью
сотрудника пока не реализовано. Существующая общая форма статуса в карточке
и административная форма продолжают работать как раньше.

Экран не отправляет письма. Письма, отправленные вручную вне программы,
нужно отметить как отправленные в карточке письма, чтобы заказ ожидал ответа.
