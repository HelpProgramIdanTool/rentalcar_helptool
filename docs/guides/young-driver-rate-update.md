# Исправление доплаты за молодых и новых водителей

Перед установкой — свежая проверенная серверная резервная копия. Код не
содержит подтверждённую владельцем ставку: она задаётся в справочнике БД.
Сохранённые цены заказов, ручные доплаты и отправленные письма не меняются.

После установки кода и проверки версии в Render Shell сначала ввести
подтверждённую владельцем дневную ставку:

```bash
read -r -p 'Confirmed fee per driver per rental day: ' YOUNG_DRIVER_RATE_CONFIRMED
```

Затем проверить план настройки без изменения данных:

```bash
uv run python manage.py configure_young_driver_rate --supplier "One Rent" --supplier "Kaizen Rent" --amount "$YOUNG_DRIVER_RATE_CONFIRMED" --valid-from 2026-11-15 --name-he "תוספת נהג צעיר / חדש"
```

Сверить обе фирмы, сумму, валюту, начало действия и отсутствие лимита с
подтверждением владельца. Для сохранения выполнить ту же команду с `--apply`:

```bash
uv run python manage.py configure_young_driver_rate --supplier "One Rent" --supplier "Kaizen Rent" --amount "$YOUNG_DRIVER_RATE_CONFIRMED" --valid-from 2026-11-15 --name-he "תוספת נהג צעיר / חדש" --apply
```

Команда сохраняет отдельный приоритетный тариф и не удаляет прежние записи.
Повторный запуск с той же датой не создаёт второй тариф. При неверной фирме
или противоречивом справочнике все изменения отменяются вместе.

Проверить пересчёт новой формы без создания заказа и без отправки писем:
один и два отмеченных водителя, несколько оплачиваемых дней. Один человек,
подходящий по обоим признакам, отмечается один раз. В письме должны быть
отдельно перечислены отмеченные водители, а услуга должна иметь их количество.

Для существующего заказа сначала открыть изменение и показать владельцу
новый расчёт. Если прежняя ручная доплата относилась к молодым водителям,
её нельзя оставить вместе с новой автоматической услугой. Убирать только
проверенную прежнюю доплату, не все ручные суммы. Изменение реального заказа
и передача UPDATE требуют отдельного подтверждения владельца; не пересылать
ранее отправленные письма автоматически. Не возвращать прежний черновик с
устаревшей суммой вместо нового проверенного письма.

После настройки и проверки — новая резервная копия справочника и базы.
