# Заявка с сайта: ручная вставка

1. Откройте «Новое обращение» и вставьте полную заявку в «Клиент написал».
2. Нажмите «Заполнить из заявки и подобрать машины».
3. Проверьте заполненные поля, выбранные группы и предупреждения.
4. Нажмите «Сохранить и перейти к расчёту». Цены берутся из загруженных тарифов.
5. Выберите варианты для письма, отредактируйте его и откройте просмотр.
6. Скопируйте оферту или отправьте отдельной кнопкой из системы.

Поддерживается размеченная форма сайта на иврите. Программа учитывает число
пассажиров, коробку передач и распознанные категории (универсал, SUV, 7 и 8/9 мест).
Багаж, собственные кресла, возраст детей и свободные пожелания требуют проверки.
Вся исходная заявка сохраняется в заметке клиента. Количество водителей по умолчанию — 1.
Неизвестные даты не подставляются автоматически. Нераспознанные города и места нужно выбрать вручную.

Сайт не подключается. Разбор заявки ничего не отправляет и не создаёт заказ.
Повторная вставка после сохранения может создать новую оферту: автоматической проверки номера заявки пока нет.
