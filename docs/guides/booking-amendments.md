# Изменение существующего заказа

В карточке нажмите «Изменить или дополнить заказ». Откроется рабочая форма с актуальными данными, именами водителей, услугами, рейсом, отелями и контактами.

1. Исправьте нужные поля. Можно выбрать другую фирму и её группу машины.
2. Нажмите «Пересчитать». Программа покажет старую и новую сумму, добавки и депозит.
3. Подтвердите актуальные условия и нажмите «Сохранить изменения и подготовить письма».
4. Проверьте получателя и текст каждого письма. Нажмите «Выслать» у нужного письма.

У прежней фирмы — UPDATE ORDER с её номером и выделенными изменёнными строками. Номер сохраняется; после отправки ожидается новый ваучер.

При смене фирмы — CANCEL ORDER старой фирме с исходными данными и номером, NEW ORDER новой фирме с новыми данными. У новой фирмы номер пока пустой. После отправки NEW заказ ожидает подтверждения. Отмена у старой фирмы считается только отправленным запросом: проверьте её ответ и возможную плату за отмену. Программа не объявляет отмену подтверждённой автоматически.

Пока все письма являются черновиками, можно вернуться к данным и исправить их. Если уже была отправка, сначала разберитесь с подготовленными письмами. Состояние каждого видно отдельно, поэтому успешное письмо не требуется отправлять повторно при сбое второго. Для повтора неудачной отправки нужно отметить, что почта проверена и письмо не ушло.

Письма направляются существующей рабочей почтой программы. Серверный запрет писем клиентам/поставщикам до перехода продолжает действовать. Для своей проверки укажите собственный адрес в поле получателя каждого письма.

Исходные данные, водители и услуги сохраняются в истории изменения. Основная карточка содержит новые актуальные условия. Редактирование не меняет общую карточку клиента и принадлежность заказа сотруднику.

Версия видна в меню программы и на технических страницах. Ссылка открывает журнал изменений. На сервере новая версия появится только после развёртывания.
