# Заказ из оферты

1. Откройте оферту из списка. Внизу выберите вариант кнопкой **Выбрать и создать заказ**.
2. Форма заполнена данными оферты. Можно изменить контакты, даты, места, автомобиль и добавки.
3. Нажмите **Пересчитать**. Приложение берёт действующий тариф для выбранных дат аренды.
4. Если сумма отличается, появится предупреждение с прежней и новой ценой.
5. Проверьте сумму, поставьте отметку подтверждения и нажмите **Создать черновик заказа**.

Изменение полей требует нового расчёта. Если тариф поменяется между расчётом и сохранением,
приложение покажет новую сумму и снова попросит подтверждение. При отсутствии тарифа заказ
не создаётся.

Оригинальная оферта и карточка клиента не изменяются. Отредактированные контакты сохраняются
в самом заказе. Сохраняются также выбранные добавки и условия расчёта.
Повторное нажатие открывает уже созданный заказ. Для отдельной альтернативы сначала создайте
копию оферты. Письмо поставщику на этом этапе не отправляется.

## Если депозит отсутствует

После нажатия «Пересчитать» откроется окно ввода суммы и валюты депозита.
Ноль допустим и означает отсутствие депозита. Пустое поле не считается нулём.

- **Только для этого заказа:** сумма сохраняется вместе с заказом, общая таблица не меняется.
- **Сохранить в базе для следующих расчётов:** заполняется отсутствующая сумма в тарифной
  группе. Для этого нужны права изменения групп автомобилей. Действие записывается в историю.
  Если несколько групп используют общий тариф, значение применяется ко всем этим группам.
- **Отмена:** окно закрывается без сохранения. Пока депозит не указан, создать заказ нельзя.

После ввода снова проверьте расчёт и подтвердите заказ. Если изменить автомобиль,
разовое значение нужно указать заново. Уже заполненный другим оператором депозит не перезаписывается.

Пока окно ввода подключено к отсутствующему депозиту при создании заказа. Отсутствующие
тарифы аренды и добавок по-прежнему останавливают расчёт с пояснением.
