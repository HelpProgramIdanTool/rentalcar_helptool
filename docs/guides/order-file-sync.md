# Синхронизация Excel по команде

В меню владельца и администратора: **Синхронизация Excel** (`/order-file/`).

1. Если вносили записи вручную, сохраните Excel и закройте книгу.
2. Выберите её в «Загрузить и проверить». На этом шаге заказы не меняются.
3. Просмотрите новые и изменённые строки. Расхождения не перезаписываются молча.
4. Подтвердите применение строк без конфликтов.
5. Скачайте результат из истории и замените им свою рабочую копию.

Сервер не имеет доступа к рабочему столу вашего компьютера. Он хранит оригинал
загрузки, результат и полную резервную копию базы перед применением. Все эти файлы
приватные и входят в архив вложений при ночном копировании. Кнопка скачивания
без загрузки Excel читает данные программы и последнюю сохранённую таблицу;
несохранённые изменения на компьютере ей неизвестны.

В файле хранится ссылка на состояние последней синхронизации. Если изменился
только Excel, изменение можно применить к программе. Если изменилась только
программа, новое значение попадает в Excel. Изменения разных полей объединяются.
Разные изменения одного поля оставляют строку на проверке. Если база изменилась
после предварительного просмотра, применение останавливается: загрузите файл заново.
Отсутствие строки в Excel не удаляет заказ из программы.

Фирма + номер используются для поиска существующего заказа. Повторы и найденные
карточки без номера с теми же email и датой требуют проверки. После связывания
используется скрытый ID карточки. Не редактируйте его. Коды фирм задаются в справочнике.

Синхронизируются имя в карточке заказа, контакты, даты и исходное описание места,
номер фирмы, сумма, статус и период учёта. Коррекция суммы сохраняется как отдельная
ручная поправка, а не подмена тарифа. История содержит значения до и после.
«Учтён» соответствует завершённой аренде, но не закрывает банковскую оплату.
Состав отдельных водителей, смену фирмы, класса и дополнительных услуг существующего
заказа корректируйте в рабочей форме заказа. Синхронизация не рассылает письма.

Новые ручные заказы сохраняются как исторические записи с исходным текстом класса,
услуг и адресов. Неполные, спорные и некорректные строки остаются в Excel с причиной.
Они не выдаются за успешно импортированные. Исходные листы и формулы сохраняются
в оригинале загруженного файла, а рабочий экспорт содержит данные заказов без внешних формул.

После развёртывания этой версии на Render ночной архив также содержит отдельный
`All_orders.xlsx`. Он формируется по расписанию резервного копирования, не импортирует
Excel в базу и не отправляет письма. Источники восстановления — полный дамп базы и
архив вложений; Excel представляет удобную дополнительную копию заказов.
Новый файл из ночного архива пока не проверялся на реальном Render; локальные проверки
не подтверждают успешное удалённое копирование после развёртывания.
