# Сверка за месяц

Откройте **Сверка за месяц** в левом меню или в административной панели.
Одна сверка — один месяц и одна фирма. Валюта этого модуля — PLN.

1. Создайте сверку, укажите первое число месяца, фирму, работника и процент.
   НДС указывайте только если он подтверждён: он нужен для перевода брутто в нетто.
2. Загрузите Excel своих записей. Проверьте лист, первую строку и буквы столбцов.
   Красное / пустая сумма считается признаком отмены только при включённом правиле.
   Цвет не отмечает новую фактуру оплаченной.
3. Загрузите отчёт поставщика и список работника. Новый файл отчёта целиком
   заменяет предыдущий, а не прибавляется к нему. Список работника также заменяется.
   Повторно загруженный одинаковый файл ничего не меняет.
4. Нажмите **Дополнить базу из моих записей**. Новые заказы создаются как черновики,
   отсутствующие данные дополняются. Существующие цены и контакты не затираются.
   Строки с расхождениями сначала нужно проверить и снабдить пояснением.
5. Разберите **Проверить**. Для строки без номера можно внести правильный номер;
   для неоднозначного совпадения — ID существующего заказа той же фирмы.
   Одинаковый email не объединяет разных клиентов.
6. Выберите включение, отмену, перенос или исключение с причиной.
   В комиссию входят только заказы работника с окончательным нетто поставщика.
   Если у поставщика только брутто, нетто рассчитывается по подтверждённому НДС.
   Отсутствие в отчёте само по себе не означает отмену.
7. **Сверка завершена** фиксирует решения. Отмены попадают в историю клиента,
   первоначальная сумма остаётся в истории. Переносы появляются в следующем месяце.
8. Внесите номер, дату и сумму своей фактуры. Сумма фактуры — не оборот аренды
   и не комиссия работника. Полученные и выплаченные суммы вводите отдельно с датами.
   Для частичной оплаты указывайте общую полученную сумму на текущий момент.

## Excel и история

При загрузке свежих записей программа ищет номер заказа в прежних сверках той же
фирмы. Ранее включённые заказы получают отметку **Учтён ранее** и не увеличивают
комиссию нового месяца. Разница в датах или сумме не мешает совпадению номера.
Если поставщик повторно включил такой номер в новый отчёт, строка остаётся на
проверке: нужно выяснить, повтор это или корректировка. Повторное начисление
блокируется; отдельный расчёт корректировок пока не предусмотрен.

Кнопка **Моя таблица с отметками прошлых месяцев** скачивает копию исходной
таблицы: прежние включённые заказы выделены жёлтым, отменённые — красным со снятой
суммой. Добавлен столбец с периодом и статусом. Жёлтый означает участие в прежней
сверке, а не получение оплаты по фактуре. Строки без номера и повторяющиеся номера
автоматически не перекрашиваются. Исходный загруженный файл сохраняется отдельно.

**Скачать Excel** доступно в любое время. Статус DRAFT означает предварительную
сверку, CLOSED — завершённую. В истории доступны все прежние версии.
В списке сверок отметьте фирмы одного месяца и выберите действие
**Скачать общий Excel выбранных сверок** для общего итога.

Версии хранятся в базе и в `private_uploads/monthly_exports/ГГГГ-ММ/ID_фирмы/`.
Оригиналы загрузок хранятся в базе с контрольной суммой. Эти данные не коммитятся.
Это локальное сохранение, а не облачная резервная копия. Для отдельного хранилища
можно настроить `RECONCILIATION_EXPORT_ROOT`. Отдельно резервируйте базу данных.

До платежей сверку можно открыть для исправления с причиной. Предыдущие Excel
сохраняются. Исправление уже оплаченной сверки намеренно блокируется: требуется
отдельная корректировка, чтобы не переписать историю платежей.

Сентябрьские сохранённые результаты перенесены как рабочие сверки. Неоднозначные
строки поставщиков остаются видимыми; получение денег и выплаты не выводятся
из цветов старых таблиц или наличия заказа в отчёте.
