# 2026.11.26.2

Prepared for deployment; live installation is not yet confirmed.

Statistics adds the top ten supplier vehicle groups ranked by booked rental days.
Columns show group/code, supplier, total days and four calendar seasons based on
pick-up month. Full rental days are assigned to that season, including rentals
crossing a season/year boundary. The existing year/date-basis filter applies.
Future reservations are included; drafts, cancellations, no-shows and archived
bookings are excluded. Missing group/date/day records are counted separately.
Historical raw group names are used only when the structured group is missing.

No database migrations or writes to existing bookings. Before deployment obtain
a fresh verified backup. Check the new table in Statistics for the selected year.
